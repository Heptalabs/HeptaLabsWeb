Security

보안 및 사용자 제어

실수 방지와 인증 분리를 중심으로 보안 UX를 설계했습니다.

핵심 보안 구성

  • 시드 구문 생성/검증/복구를 분리해 초기 설정 오류 최소화
  • 전송 전 주소·체인·수량·수수료 확인 단계 고정
  • 확인 이후 PIN/생체 인증 실행으로 의도 확인 강화
  • 기록 상세에서 트랜잭션 해시/수수료/상태 일관 표기

사용자 제어 포인트

  • 자산 주소록/NFT 주소록 분리로 전송 대상 혼선 방지
  • 최근 전송 목록 + 라벨/메모로 재전송 정확도 향상
  • 기록 필터(자산/NFT/체인/기간)로 조회 범위 즉시 축소
  • 다국어/테마 환경에서도 동일한 경고/오류 UX 제공

리스크 대응 매트릭스

오입력 전송

확인 화면 고정 + 재인증 단계로 사고 가능성을 낮추고, 주소록 라벨링으로 입력 실수를 줄입니다.

기기 분실/도난

PIN/생체 인증 잠금과 시드 기반 복구 정책으로 계정 접근 통제를 강화합니다.

기록 추적 누락

필터 기반 기록 조회와 상세 내역 통일로 문제 발생 시 빠른 역추적이 가능합니다.

보안 운영 체크리스트

사용자 측면

  • 새 기기에서 복구 후 첫 전송은 소액 테스트로 주소 일치 여부 확인
  • PIN/생체 인증 정책 변경 후 잠금 해제 동작을 즉시 재검증
  • 중요 전송은 주소록 라벨, 체인, 수량을 확인 화면에서 한 번 더 점검

민감 작업 보안 프로세스

잠금 해제 진입

앱 재진입/민감 메뉴 접근 시 잠금 해제를 먼저 실행해 지갑관리, 주소록관리, 보안 설정의 무단 접근을 줄입니다.

전송 전 검증

전송 직전 주소, 네트워크, 수량, 수수료를 한 화면에서 검증하고, 마지막 인증 단계로 사용자 의도를 다시 확인합니다.

사후 추적 및 복구

문제 발생 시 기록 상세(해시/상태/수수료)를 기준으로 역추적하고, 필요하면 시드 기반 복구 절차로 연속성을 유지합니다.
