Features

앱 핵심 기능

실사용 중심으로 자주 쓰는 기능을 구조화해 제공합니다.

기능 카테고리 맵

주요 기능을 실제 사용 흐름 기준으로 3개 카테고리로 나눠 확인할 수 있습니다.

온보딩/지갑 설정

생성, 복구, 백업 검증까지 초기 설정 단계를 체계화했습니다.

자산 운용/전송 실행

자산 조회, 전송, 기록 추적을 짧은 경로로 연결했습니다.

보안/탐색/확장

인증 정책, Discover, 운영 확장 포인트를 함께 제공합니다.

온보딩 및 지갑 라이프사이클

처음 시작부터 지갑 복구까지 핵심 초기 플로우를 안정적으로 안내합니다.

멀티 지갑 생성/복구

지갑 생성과 복구를 하나의 일관된 플로우로 제공해, 시작 단계에서의 오류 가능성을 줄입니다.

  • 생성/복구 진입 경로를 통일해 초보 사용자도 단계별 진행이 쉽습니다.
  • BIP39(12/24 단어) 기반 시드 복구 시나리오를 기본으로 지원합니다.

지갑 이름/기본 지갑 규칙

기본 지갑 네이밍 규칙을 적용해 여러 지갑을 만들어도 사용자 혼선이 적도록 설계했습니다.

  • 기본 이름 충돌 시 번호를 자동 증가해 지갑 목록 가독성을 유지합니다.
  • 사용자가 직접 입력한 사용자 정의 이름은 언어 변경 후에도 그대로 보존됩니다.

백업 검증 중심 온보딩

시드 구문을 단순 표시로 끝내지 않고, 재입력 검증 단계까지 포함해 안전성을 높였습니다.

  • 검증 단계에서 오입력 포인트를 즉시 확인할 수 있습니다.
  • 온보딩 완료 후 앱 잠금 정책(PIN/생체)을 연계 적용할 수 있습니다.

자산 운용 및 전송 실행

조회-전송-기록 확인까지 실제 사용자가 가장 자주 반복하는 동선을 최적화했습니다.

자산/NFT 분리 보기

보유 자산과 NFT를 분리한 화면 구조로 탐색 속도와 전송 정확도를 높였습니다.

  • 자산 타입별로 필요한 정보만 보여줘 화면 피로도를 줄입니다.
  • 토큰과 NFT 전송 플로우를 구분해 잘못된 전송 시도를 줄입니다.

전송/수신 중심 실행 UX

자주 쓰는 액션을 상단에 배치해 최소 탭으로 전송/수신 흐름에 접근할 수 있습니다.

  • 최근 대상/주소록을 재사용해 반복 전송 시간을 줄입니다.
  • 확인 단계에서 주소, 체인, 수량을 다시 검증하도록 설계했습니다.

주소록/기록 추적 체계

자산/NFT 주소록 분리와 기록 필터를 결합해 실수 방지와 사후 추적성을 함께 강화했습니다.

  • 자산 주소록과 NFT 주소록을 분리해 대상 혼동을 줄입니다.
  • 기록 상세에서 상태, 수수료, 해시를 빠르게 확인할 수 있습니다.

보안 제어 및 서비스 확장성

민감 기능 보호와 콘텐츠 탐색, 운영 연동 구조를 한 흐름으로 관리합니다.

보안 인증 단계

전송 확인 후 PIN/생체 인증을 분리해 단계별 사용자 의사결정을 명확히 합니다.

  • 지갑관리/보안/주소록관리 등 민감 메뉴 접근 시 잠금 해제를 요구합니다.
  • 생체인식 사용 시 디바이스 등록 상태에 따라 정책적으로 동작합니다.

Discover 탐색 콘텐츠

DApps, 인기 토큰, 즐겨찾기, 브리핑을 하나의 탭에서 자연스럽게 탐색합니다.

  • 지갑 밖 이동을 줄여 사용 흐름과 보안 맥락을 유지합니다.
  • 카테고리 단위로 콘텐츠를 관리해 운영 업데이트가 빠릅니다.

다국어/테마 + 모듈형 구조

KO/EN/中文 및 Light/Dark 전환을 전반에 일관 적용하고, 백엔드/API 연동 확장성을 고려했습니다.

  • 언어 전환 시 핵심 정책/문구를 같은 의미로 유지하도록 관리합니다.
  • 모듈형 구조로 기능 추가와 운영 유지보수에 유연하게 대응합니다.
