Usage Flow

IMWallet 사용 흐름

처음 시작부터 일상 사용까지의 핵심 단계를 정리했습니다.

단계별 사용자 여정

1

앱 설치

APK 설치 후 최초 실행 상태와 기본 권한/환경을 점검합니다.

2

지갑 생성 또는 복구

시드 구문 생성/복구를 선택하고 안내에 따라 안전하게 설정합니다.

3

보안 잠금 설정

PIN 및 생체 인증을 활성화해 앱 접근 보호 레벨을 설정합니다.

4

자산/ NFT 확인

보유 목록을 확인하고 필요한 체인/토큰/NFT로 화면을 전환합니다.

5

전송/수신 실행

주소록 및 최근 대상 활용 후 확인/인증 단계를 거쳐 전송합니다.

6

기록 추적

필터와 상세 화면으로 트랜잭션 상태/수수료/해시를 검증합니다.

온보딩 체크리스트

  • 시드 구문 저장 위치 확인 및 재입력 검증 완료
  • PIN 오류/생체 인증 실패 시 재시도 UX 점검
  • 기본 지갑/체인 선택 상태가 홈에 올바르게 반영되는지 확인

흐름 안정성 기준

입력/스크롤 안정성

키보드 노출 시 입력창 가림, 하단 버튼 밀림, 긴 리스트 스크롤 끊김 같은 모바일 실사용 이슈를 우선 점검합니다.

상태 유지 일관성

화면 이동이나 언어/테마 전환 이후에도 선택한 지갑, 체인, 탭 상태가 보존되도록 설계해 재작업 비용을 줄입니다.

완료 피드백 명확성

생성/복구/전송처럼 중요한 단계는 즉시 완료 피드백을 제공해 사용자가 다음 행동으로 자연스럽게 이어지도록 구성합니다.
