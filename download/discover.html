Icon Fallback

아이콘 로드 실패 시 대체 이미지/텍스트를 적용해 레이아웃 깨짐을 최소화합니다.

다국어 용어 통일

카테고리/버튼 명칭을 KO/EN/中文에서 의미 일관성을 유지하도록 관리합니다.

탐색 동선 설계

  • 홈 자산 확인 → Discover 탐색 → 전송/기록 확인으로 자연스럽게 연결
  • 외부 이동 최소화로 보안 맥락과 작업 집중도 유지
  • 탭 간 이동 시 현재 지갑/체인 컨텍스트를 최대한 보존

Discover 운영 품질 기준

콘텐츠 신뢰도

카테고리 노출은 운영 정책 기준으로 관리하고, 링크/아이콘 오류 시 대체 UI를 제공해 사용 흐름 단절을 최소화합니다.

탐색 효율

즐겨찾기/인기 토큰/브리핑을 함께 배치해 사용자가 외부 검색 없이 앱 내에서 탐색-판단-실행을 이어가도록 설계했습니다.

지표 기반 개선

클릭률, 체류 시간, 이탈 구간을 기준으로 카테고리 우선순위를 재조정해 릴리즈마다 탐색 품질을 누적 개선합니다.
