# Phase 02 - 프로덕션 스트리밍 (실서비스)

## 목표
- 패키징 빌드 기반 Pixel Streaming 서비스 구성
- 다중 사용자 접속/안정성/화질 조정

## 작업 체크리스트
1. UE5 프로젝트 패키징 빌드 생성
2. Pixel Streaming 인프라(Signalling/Web) 구성
3. 브라우저 접속 URL 고정
4. 운영 지표 점검
   - 평균 지연
   - 해상도/비트레이트
   - 동접 안정성
5. 계정/DB/게임 로직 연결
   - 로그인
   - 코인/인벤토리 영속화
   - 상점/카지노 밸런싱

## 합격 기준
- 목표 해상도에서 프레임 안정 유지
- 접속/재접속 실패율이 운영 기준 이내
- 핵심 기능(광장/상점/게임장)이 브라우저에서 동작
